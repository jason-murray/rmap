rMap

Advanced input tooling for iRacing. Map your wheel, pedals and button boxes onto one virtual device - with layers, multibinds and telemetry-aware bindings - plus teleFFB, a 360 Hz telemetry-driven force feedback engine.

Download for Windows Requires iRacing · all releases

Mapping

One device for everything

Routes every wheel, pedal set and button box onto a single vJoy virtual device, with a guided binding window that walks iRacing's options screen with you - capture, label and trigger each output.

Layers

Multiply your buttons: a layer button temporarily remaps others to alternate outputs, reverting after an inactivity timeout.

Multibind

One button, three functions: short press, long hold and double tap each fire their own output.

Gated bindings

Bindings that only apply while a telemetry condition holds - above a speed, in the pits, stopped, off throttle. The same button can do different things at speed and in the pit lane.

Race helpers

Brake Magic drag from a button, hold-to-shift into reverse that reads the actual gear, and X Guard to stop throttle/brake overlap.

Encoders & mouse

Subdivide fine-stepped encoders into chunkier steps, and drive the Windows mouse cursor from your funky switch for iRacing's clickable black boxes.

teleFFB

360 Hz telemetry FFB

Replays iRacing's full 360 Hz steering-shaft torque signal to your wheelbase at up to 1000 Hz output - detail mode for texture, low-latency mode for response.

Tuned your way

Strength, drive with soft-clip, smoothing, and additive effects from suspension telemetry - kerb strikes and fine road texture.

Get started

  1. Download and run the installer.
  2. rMap walks you through installing the bundled vJoy driver and configuring the virtual device - one click each.
  3. Select your devices, start the pipeline, and bind the outputs in iRacing using the guided Binding window.
  4. For teleFFB, disable iRacing's own force feedback and press Start FFB - rMap remembers your wheelbase and starts automatically next time.

Updates are built in: rMap checks for new versions at launch and installs them with one click.
